# Контракт перед реализацией

Дополняет spec-dimension-filters-clean-viewport-2026-10-25.md. Сохраняет пять фильтров и internal-only default. Canonical SPEC и геометрические источники истины не меняются. Исследование и точные действующие редакции стандартов: docs/research/DRAWING-GOST-AUDIT-2026-10-25.md (независимая проверка перед размерным slice).

## E1 — завершённое создание возвращает Руку

Успешная Durable Revision создания стены/проёма/предмета возвращает activeTool=select. Следующий жест выбирает объект или перемещает вид. Сохранение нового элемента ровно одно. Невалидный черновик, отказ хранилища, отмена или промежуточный conflict-preview не считаются успехом. После успешного повтора публикации также вернуть Руку; не терять ошибку или точный ожидающий кандидат до успешного сохранения. После принятия controller-ом неудавшейся публикации исходный интерактивный черновик поглощается: точный кандидат принадлежит controller и доступен в Recovery export; новый отменяемый черновик поверх него не создаётся. Если нужны несколько стен, пользователь явно выбирает «Стена» для каждой. Прежние тесты непрерывного рисования переходят на этот контракт через настоящий UI.

## E2 — размерный чертёж

Разделить сторону выноса линии и сторону чтения числа. Весь повёрнутый текст располагается над своей размерной линией с зазором, включая нижние/левые/правые/45° линии. Число не пересекается никакой линией. Засечки строительного чертежа 45°, выносные линии перпендикулярны размерным, значения без суффикса «мм»; единицы в настройках.

Набор минимально достаточен: две внутренние длины прямоугольной комнаты; для ломаных комнат независимые участки без повторных коллинеарных фрагментов; общие габариты один раз на направление; цепь проёмов/простенков единым рядом для одного прямого участка стены. Совпавшие измерения с одинаковыми реальными опорными точками и базой измерения не дублируются. Разные опорные базы нельзя объединять только из-за равенства числа.

Ряды детерминированы, части одной цепи не разбрасываются случайно по шести полосам. Полный суммарный размер дальше частичных. В тесном виде скрываются второстепенные конфликтующие аннотации, а не рисуются наложенные цифры/выноски. Масштабирование открывает доступные подробности без изменения геометрии. Дедупликация и выбор до screen layout; фильтр не сбрасывает pan/zoom. Экранные CSS-пиксели не выдавать за физические миллиметры листа; формальное соответствие масштабному печатному чертежу не заявляется без экспорта/калибровки. Подробные клаузы и ограничения фиксируются в исследовании.

## E3 — оси и отсутствие подсказок

Не показывать координатные оси/триады в 2D/3D. Сетка редактирования и манипулятор поворота — функциональные органы, а не координатные оси. Удалить инструкции/легенды/советы в рабочем проекте, включая скрываемые только на узком экране. Оставить реальные ошибки, подтверждения команд, сохранение/восстановление/PWA update, имя выбранного предмета и доступные названия кнопок. Лишних поясняющих карточек в покое/выборе/размещении нет.

## E4 — поворот до установки

Общий AppShell draft yawRadians передаётся в 2D/3D и сохраняется при переключении вида. При выборе новой модели yaw=0. До выбора точки доступны ±45° и значение угла; после появления preview сразу виден удобный манипулятор без предварительного вращения. Изменение угла — только черновик, 0 Durable Revision. Preview, collision/room validation и окончательное сохранение используют один и тот же угол/центр/габариты для placeholder, catalog GLB, custom GLB и повторно используемой модели. Для 3D draft не подменяет durable selectedItem и не отправляется в update-existing-item controller.

Подтверждение публикует одну Revision с выбранным yaw, переводит в Руку. Отмена не создаёт ресурсов/Revision. Невалидный повёрнутый footprint нельзя подтвердить. В процессе жеста: pointercancel/lost capture/второй палец отменяют жест без публикации; рабочие PWA safety и read-only блокировки сохраняются. Сохранённая выбранная мебель имеет манипулятор сразу при выборе.

## E5 — окно без настройки подоконника

Убрать поле «Высота подоконника» из создания и редактирования окна и соответствующие советы. Не изменять существующие проёмы/backup. Геометрическая нижняя отметка проёма остаётся внутренним обязательным данным модели: существующая сохраняется, новый Window использует проверенный фиксированный default. Это не отдельная подоконная доска/настраиваемая функция. Высота/ширина и проём в 3D остаются согласованы.

## E6 — устойчивый 3D кадр

Воспроизвести артефакты последовательностями: пустая комната → orbit/pan/zoom → cutaway/all walls → resize/orientation → selection/cancel placement → добавление/удаление предмета → 2D↔3D; отдельно raw WebGL2 fallback и Three/GLB, context loss/recovery. Устранить найденную причину устаревшего framebuffer/depth/сцены/ракурса, а не очищать его фиктивной вставкой предмета. Каждый кадр соответствует текущей сцене и размеру canvas; disposable resources освобождаются; фактические ошибки не маскируются. Доказательства unit+browser/pixels и честные ограничения физического телефона в отчёте.
