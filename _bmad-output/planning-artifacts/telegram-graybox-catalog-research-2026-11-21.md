Габарит задаёт внешний объём. Для углового дивана и иных сложных форм точные
проверки размещения и зазоров продолжают использовать допустимый footprint V1.
Тип открывания дверцы, монтажная ниша, разъёмы и обслуживаемые зазоры требуют
измерения конкретного изделия. Для ковра стоит проверять представление
существующих предупреждений о пересечении с мебелью. Каталожные карточки
используют собственные силуэты и простые цвета в рамках FR-60.

## Палитра

В каталоге фасадов «Лемана ПРО» встречаются белый, бежевый, серый, зелёный,
древесный, графитовый и тёмно-синий. Hoff также использует бытовые названия
оттенков в фильтрах. Лемана ПРО описывает сочетания глубокого зелёного с
кремовым, бежевым, светло-серым, терракотой и синим. [Фасады «Лемана ПРО»](https://storage.yandexcloud.net/lemanapro-ru-landings-docs/storage/LemanaPro_Storage_Catalog.pdf) · [«Тайга» и сочетания](https://lemanapro.ru/journal/cvet-goda-ot-lemana-pro-tayga/) · [Фильтры цвета Hoff](https://hoff.ru/catalog/gostinaya/osveschenie_dlya_gostinoy/)

Для этого расширения подходят действующие пары V1. Дерево и орех дают два
варианта отделки, синий, фиолетовый, терракота, зелёный и ягодный дают
достаточно различий для сравнения. Примеры сочетаний в TMA: «Лесной зелёный»
с «Тёплым деревом», «Глубокий синий» с «Орехом», «Мягкий фиолетовый» с
«Тёплым деревом».

| Название в TMA | V1 ID | Экранное значение |
|---|---|---|
| Тёплое дерево | `alpha-warm-wood` | `#a76a3b` |
| Глубокий синий | `alpha-blue` | `#416b91` |
| Мягкий фиолетовый | `alpha-violet` | `#716796` |
| Орех | `alpha-walnut` | `#8c6e4c` |
| Терракота | `alpha-terracotta` | `#835a45` |
| Лесной зелёный | `alpha-forest` | `#536d62` |
| Ягодный красный | `alpha-berry` | `#8a4f54` |

Следующий кандидат для проверки совместимости V1 — нейтральная группа из
тёплого белого, песочного, светло-серого и графита. Пример справочного кода
краски `NCS S 0502-Y` приведён в каталоге, размещённом «Лемана ПРО». Магазин
также приводит `Pantone 18-0312 TCX` для своего оттенка «Тайга». Коды относятся
к названным образцам источников. Для публикации в TMA потребуется подтверждённая
связь кода с выбранным цветом и отдельная проверка формата по AD-33. [Каталог NCS](https://cdn.lemanapro.ru/lmru/image/upload/v1618487319/lmcode/JiA6PbIbrEq_RhO1DEhcSg/82167081_ins.pdf) · [Справка по обозначению «Тайга»](https://lemanapro.ru/journal/cvet-goda-ot-lemana-pro-tayga/)
