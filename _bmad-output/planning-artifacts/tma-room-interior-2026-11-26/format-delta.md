# Закрытая грамматика расширения Runtime V1

Предложение для записи в [реестре ingress](../../specs/spec-interiors-editor-alpha/portable-backup-ingress-registry.md) после принятия пакета. Семантика опор и стороны определена в [AD-41–43](architecture-delta.md). Базовые ветви дополняются явным новым селектором. Открытие файла авторитетно проверяет объявленную пару до декодирования в новый Project.

## Выбор схемы

| Граница | Предлагаемая форма |
| --- | --- |
| Локальная модель и checksum | Корневой `interiorSchemaVersion: 1` в семействе Project V1 при использовании хотя бы одного свойства ниже. Сериализуется та же ревизия и вся структура A/B. Последнее удалённое расширение убирает дискриминатор при следующей штатной публикации. |
| Локальная запись | Telegram account IDB 6. Допуск writer capability относится к соединению и проверяется вместе с fence до смены указателя. Прежние локальные форматы читаются в своих режимах, при необходимости upgrade проходит штатно. |
| Portable .interiors | Пара `interiors.project/runtime-v1-interior-details@1` одна для Manifest и JSON Project member. Для представимой записи writer автоматически выбирает самый узкий совместимый текущий селектор. Кандидат с любым из новых значимых свойств требует новой пары. |
| A/B | Поля, правила и прежний селектор `interiors.project/runtime-v1-room-layouts@1` определяет AD-40. Состояние только с A/B может использовать прежнюю пару. Состояние с A/B и новым интерьером использует новую расширенную пару, включающую ту же семантику. |

## Новые ветви Project JSON

Ниже перечислены добавляемые ключи. Поля уже зарегистрированных ветвей сохраняют своё прежнее написание, ограничения и лексемы. Неизвестный ключ, дубль ключа, незарегистрированная версия или недопустимая комбинация отклоняются до публикации. Отсутствие назначения отделки кодируется отсутствием свойства. Пустая запись сторон канонизируется как отсутствие `sideFinishes`.

| Адрес | Закрытые данные расширения |
| --- | --- |
| `level.rooms[*].floorFinish` | Пара `{presetId, version}`. Ключи V1 `light-oak`, `matte-floor-tile`, `plain-floor`, версия 1. |
| `level.wallSegments[*].profile` | `partition` или `bearing`. Действительное значение по-прежнему в `thicknessMm`, у старых стен классификация отсутствует. |
| `level.wallSegments[*].sideFinishes` | Ключи `left` и/или `right`, каждый содержит `{presetId, version}`. V1 `warm-white-paint`, `sand-paint`, `muted-green-paint`, `neutral-wall-tile`. Физическая сторона задаётся AD-41. |
| `level.openings[*]`, Door | Отсутствие варианта означает глухую распашную дверь. `variant: "glazed-swing"` использует прежние `swingSide` и `hingeEnd`. `variant: "sliding"` требует `slideSide: "left"|"right"` и `slideDirection: "toward-start"|"toward-end"`. В раздвижной ветви поля петель и распахивания отсутствуют. Смена обратно на глухую убирает вариант и поля сдвига. |
| `level.openings[*]`, Window | `sections: 1|2` задаёт явное число секций. Отсутствие сохраняет legacy автоделение. Поля двери отклоняются. |
| Напольный встроенный экземпляр | `catalogPreset?: {presetId, version}`. Версия 1 означает явный зарегистрированный встроенный пресет TMA. Реестр объединяет 30 существующих ID и `table-lamp`, `book`, `vase`. Наличие `assetDefinitionId` исключает эту пару. Метка продолжает служить отображаемым значением. |
| `assetInstances[*]`, гость на опоре | `anchorClass: "support"`, обязательные поля `assetInstanceId`, `label`, `widthMm`, `depthMm`, `heightMm`, `color`, `catalogPreset`, `supportAssetInstanceId`, `supportSurfaceKey`, `offsetXMm`, `offsetZMm`, `relativeYawMilliDeg`, `context`. Допускаются `colorVariantId` и `locked: true` по прежним правилам. Ключи гостей `planter`, `table-lamp`, `book`, `vase`. Мировые X/Z, абсолютный угол, производимая отметка основания и `assetDefinitionId` в ветви отсутствуют. |
| Проверочный `context` гостя | Обязательный `roomId` и `layoutId` только для явно записанной расстановки. При чтении должны совпадать с разрешённой опорой. Записываются из опоры при сериализации, отдельного редактируемого адреса в домене нет. Это выявляет ссылку на другую комнату/расстановку при подмене только Host ID. |
| Ключ версии площадки | `top` у `table`, `desk`, `coffee-table`, `bedside-table`, `dresser`, `tv-stand`. У `open-shelf` — `shelf-1` … `shelf-5` снизу вверх, включая верхнюю площадку с просветом до потолка. Версия определяется парой на опоре. Новая несовместимая геометрия требует новой версии и согласованной доменной мутации. |

Добавляемые числовые поля проверяются как канонические целые лексемы ещё в raw ingress. Версии только 1, секции только 1 или 2, относительный угол от 0 до 359 999 тысячных градуса, смещения — знаковые безопасные целые миллиметры по общему представлению координат. После разбора проверяется принадлежность опоре, допустимый footprint и свободный объём для обеих расстановок. Ссылка на гостя как опору, цикл, неизвестная площадка и поля неподдерживаемого якоря дают отказ общего кандидата.

## Матрица переноса и отказов

| Вход | Ожидаемое действие |
| --- | --- |
| Незатронутая прежняя Durable Revision | Прочитать по прежним правилам и сохранить исходные байты. При экспорте выбрать действующий представимый селектор. |
| Новый .interiors на IDB 4/5 или у читателя без пары | Показать требование совместимой версии. Не создавать Project, запись ресурса или новый указатель. |
| Новый .interiors в чистом совместимом профиле на IDB 6 | Проверить архив, назначить новый ID импортированного Project и новую локальную Revision. Сохранить внутренние ID стен, проёмов, опор и их гостей в новом пространстве проекта. Exact-ресурсы сохранить по исходным хешам. |
| Несогласованный witness, изменённый cache или malformed raw number | Отвергнуть до pin и записи. Исходный архив и ранее сохранённые локальные проекты доступны для прежних действий. |
| Legacy export при невозможности lossless representation | Выгрузить поддерживаемый новый селектор. Возможность старого формата определяет наличие данных, нуждающихся в расширении. |
| Запись прервана upgrade, fence, квотой или validation | Атомарный отказ с прежним указателем и согласованными ресурсами. Проверить конкурентные вкладки и безопасное повторение. |
