# Статистика Telegram Mini App

## Обычная сборка

До первого учитываемого входа и в настройках можно выключить статистику на устройстве. Суточный и двухчасовой подсчёт обычных открытий управляются одним переключателем, который по умолчанию включён. Для измерения повторных открытий пользователь отдельно разрешает приложению помнить предыдущие открытия на этом устройстве. При следующем подходящем входе приложение может отправить дополнительный пустой запрос. Закрытие формы ничего не разрешает. Приложение не связывает открытия между устройствами и не передаёт приёмнику редакцию лицензии, время согласия, аккаунт, Telegram ID, файлы или планировку.

| Показатель | Как читать |
| --- | --- |
| Сумма параметра `tma_opens` | Число полученных сигналов открытия за московские сутки. Сигналы от пользователей с выключенной статистикой отсутствуют. |
| Сумма параметра `tma_repeat_opens` | Число полученных сигналов добровольного повторного использования на том же устройстве. Это количество открытий. Для доли удержанных людей этих данных недостаточно. |
| Сумма параметра `tma_opens_2h` | Обычные открытия из Telegram на iOS и Android за закрытые интервалы по два часа. Сумма доступна с первого полного наблюдаемого интервала. |

Суточные записи поступают в счётчик `114493478` с общим служебным ClientID. Для двухчасовых записей используется отдельный постоянный служебный ClientID в том же счётчике. Показатель «Визиты» считает служебные визиты Метрики. Для каждого отчёта нужна сумма конкретного параметра. Виджет, который суммирует все параметры, смешивает открытия с повторами и двухчасовыми суммами. За 23 ноября 2026 года проверены строки `tma_opens` — 26 и `tma_repeat_opens` — 9. [Дашборд суточных открытий](https://metrika.yandex.ru/dashboard?id=114493478&dashboardId=47721ca6-23fd-42ca-825a-fd04a9ca1417) · [Отчёт за 23 ноября](https://metrika.yandex.ru/stat/new?id=114493478&period=2026-11-23%3A2026-11-23&group=dekaminute&isMinSamplingEnabled=false&currency=RUB&attr=%7B%22attributionId%22%3A%22LastSign%22%2C%22isCrossDevice%22%3Atrue%7D&isUndefinedEnabled=false&view=Linear&sortBy=-ym%3As%3AsumParams&showTotal=true&chartView=Line&table=visits&metricValueMode=Absolute&screenMode=Default&sh=a6fea14c4996a9046efcc80e57e0b4a8)

Для запроса к API отчётов укажите `ids=114493478`, `date1`, `date2` и передайте значение `metrics` с фильтром внутри каждой метрики. Тогда сумма для каждого ряда учитывает свой ключ. [Фильтры метрик в API](https://yandex.ru/dev/metrika/ru/stat/segmentation#primery-ispolzovaniya-operatorov)

```text
ym:s:sumParams[ym:s:paramsLevel1=='tma_opens'],ym:s:sumParams[ym:s:paramsLevel1=='tma_repeat_opens']
```

Двухчасовой отчёт использует `ym:s:sumParams[ym:s:paramsLevel1=='tma_opens_2h']`.
Выберите московское время и двухчасовые интервалы. Сумму за интервал можно
также получить из двух соседних часовых значений. Техническое событие
отмечено последней секундой интервала. Таймаут визита счётчика должен быть
меньше 120 минут, чтобы соседние окна двухчасового ряда оставались отдельными.
Фактические отправки и время начала проверяются по журналу коллектора.
[API временных рядов](https://yandex.ru/dev/metrika/ru/stat/openapi/bytime)

Для перехода администратор сначала обновляет коллектор, сохраняет существующую SQLite, проверяет готовность приватного сервиса и таймера, затем выпускает версии сайта и каталога. В состав обычного архива сайта коллектор не входит. Старая конфигурация, физическая проверка Telegram Desktop и её данные относятся к прежнему релизу. Текущий статус публикации подтверждается отдельной записью о выпуске. [Установка, сверка и выключение](../../scripts/analytics/README.md)

## Использование редактора и ошибки

При отдельном разрешении мобильный Mini App учитывает каждый вид события
один раз за проверенный запуск. Один запуск может присутствовать в нескольких
строках. На суточных графиках и в таблицах используется «Сумма параметров
визитов» по коду. Техническое число визитов Метрики здесь не служит
показателем аудитории. Суммы обновляются после каждого закрытого
двухчасового интервала с событиями. Основные графики складывают эти суммы
по московским дням. За периоды до первого успешного получения данных в
Метрике чисел нет.

Новые отчёты складывают события всего мобильного Mini App в одну сумму.
Двухчасовые записи имеют суффикс `/mobile`, а принятые до смены редакции
суточные записи сохраняют прежние суффиксы `/ios` и `/android`. Фильтр
по префиксу группы включает обе редакции. Числа относятся к согласившейся
выборке. Ряд обычных открытий измеряет другую выборку.

Обычно отправка двухчасовых итогов начинается в 00:05, 02:05, 04:05 и так
далее по Москве. Промежуточные запуски позволяют повторить подтверждённый
отказ. В Метрике дата задаётся последней секундой закрытого интервала.
При почасовой сверке двухчасового ряда используйте служебный адрес
с суффиксом `/mobile` и таймаут визита счётчика менее 120 минут. У текущего
счётчика настроены Москва и 30 минут. В день перехода суточные и двухчасовые
суммы относятся к разным поступившим сигналам.
