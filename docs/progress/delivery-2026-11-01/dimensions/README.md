Пункт 4 запроса владельца: осевые размеры стен и простенков исключены из интерфейса и отображения, включая ранее сохранённые включённые настройки. Каноническая геометрия и расчёт измерений не меняются. Формат локальных предпочтений v1 сохранён, retired поля при чтении и записи нормализуются в false.

Фильтр разделён на вкладки «Помещения» (внутренние размеры / внешние габариты) и «Проёмы» (ширина проёмов). «Показать всё» включает только поддерживаемые группы. Вкладки поддерживают стрелки, Home/End, выбранную семантику, focus trap и возврат фокуса. Иконкой кнопки открытия управляет AppShell в соседнем срезе.

## Интеграция с итоговым интерфейсом

Мигрированы три браузерных файла: фильтры, сенсорные проёмы, завершение создания. Undo/redo проверяются непосредственно на холсте; для перемещения проёмов точный durable snapshot остаётся неизменным до «Применить». Проверки прежнего жеста разделения заменены отсутствием жеста/контролов без изменения геометрии и отменой нового перемещения через Escape. Проверены динамический заголовок «Новое окно», новая точка «Импорт модели», собственный контекст окна без панели стены. Фильтр дополнительно проверен на 320×568 и430×932 с текстом200%.

Совместный запуск 34 сценариев: 31 PASS, 3 падения ([лог](combined-ui-initial.log)). Два относились к setup: раскрытая панель закрывала повторное нажатие стены; контекст выбранной стены правомерно отсекал размер под инспектором. Setup закрывает панель/снимает выбор перед самостоятельной проверкой фильтров, все строгие размеры, значения и durable assertions сохранены. Третье выявило реальную потерю ошибки при невалидном переносе проёма: корневой срез вернул preview-валидацию до модального подтверждения. Точечный повтор всех 3 исправленных случаев PASS ([лог](combined-ui-corrections-green.log)); остальные 31 не менялись. Это суммарное покрытие 34 сценариев, не единый финальный sweep — общий регресс выполняется отдельно. Форматирование трёх мигрированных файлов PASS ([лог](migrated-ui-lint.log)).

## Совместимость старого размерного регресса

`drawing-dimensions-e2e.spec.ts` полностью приведён к текущему контракту. Удалены только ожидания осевых стен/простенков, которые теперь запрещены. Сохранены точные внутренние 4000/3000 и внешние 4200/3200 мм, ширина проёма 900 мм, независимость отображения от Durable Revision, коллизии настоящих текстовых glyph bounds, масштабирование, идентичность предметов, Undo и retry после quota failure. Перемещение клавишей меняет точный offset на 100 мм и добавляет одну ревизию только после «Применить». Проверена отдельная размерная линия проёма без retired групп. Все 9 сценариев прошли одним запуском за 18,5 с: [лог](drawing-dimensions-migrated-green.log). DOM narrowing к SVGLineElement проверен общим typecheck.
