# Проёмы: владение подтверждённой правкой при ошибке сохранения

Независимый UI-review воспроизвёл ошибку: после подтверждения переноса окна и сбоя записи в IndexedDB успешное повторное сохранение оставляло прежнюю модалку. Она содержала старую базовую Revision, блокировала историю и при повторном «Применить» показывала ложное сообщение «План изменился». Аналогичная оставшаяся модалка найдена при создании двери и окна.

После принятия кандидата контроллером диалог редактирования/создания закрывается даже при сбое публикации. Точная несохранённая правка принадлежит контроллеру и доступна через отдельную ошибку сохранения, повторную запись и выгрузку для восстановления. Отмена UI-черновика не должна создавать второе владение уже подтверждённым кандидатом. Ошибки до принятия кандидата сохраняют возможность исправить или отменить черновик.

Владелец AppShell исправил поведение. `release-opening-recovery-e2e.spec.ts` содержит три браузерных проверки:

- Перенос окна: до успешного Retry сохранённая геометрия неизменна; после Retry появляется ровно одна Revision со сдвигом на 100 мм; прежняя модалка отсутствует; Undo восстанавливает прежнее положение.
- Создание двери и окна: до Retry в сохранённом проекте нет проёма; модалка передаёт владение контроллеру; скачанный recovery-кандидат в точности совпадает с единственным сохранённым проёмом после Retry; новая Revision одна; режим выбора и история доступны; Undo удаляет созданный проём.

Исходные RED-прогоны подтверждают оставшийся диалог в каждом маршруте (`expected 0 / received 1`). Итоговый GREEN — **3 / 3**; Biome — без замечаний. Дополнительная визуальная проверка на ширине 320 CSS px показала отдельные параметры окна без параметров стены, отсутствие горизонтального переполнения и 48-px поля/кнопки создания.

Это целевой регресс, а не итог проверки всего продукта. Снимок `stale-modal-after-retry-before-fix.png` показывает исходную ошибку; `selected-window-320px.png` — проверенный узкий экран. Производственные изменения принадлежат общему интеграционному срезу AppShell; хеш в этой папке фиксирует тест.
