# Подтверждения действий · 5 сентября 2026

Шесть снимков работающего редактора из итогового браузерного прогона.
Проекты созданы в изолированных профилях; ошибки хранилища воспроизводятся
тестами. Это эмуляция телефона, не проверка на физическом устройстве.

## Удаление проекта

Диалог называет проект и объясняет необратимое удаление его локальных версий.
Безопасный выбор «Оставить проект» получает фокус. Фон недоступен до отмены
или завершения операции. Снимок — 390 × 664 CSS px.

![Подтверждение удаления проекта](dialog-project-delete.png)

## Очистка истории

Диалог объясняет, что текущий сохранённый план останется, а Undo/Redo будут
потеряны. Предыдущее предупреждение скрыто, чтобы не создавать ещё один слой
подтверждения. Снимок — 393 × 852 CSS px.

![Подтверждение очистки истории](dialog-history-discard.png)

## Удаление не выполнено

Отказ хранилища оставляет диалог открытым, данные — без изменений, а повторную
попытку — доступной. В этом проверочном проекте намеренно используется
длинное имя без пробелов: оно переносится внутри карточки.
Снимок — 393 × 852 CSS px.

![Ошибка удаления проекта](dialog-project-delete-error.png)

## Не удалось проверить текущий план

Очистка истории останавливается, если проверка безопасности не завершилась.
Ошибка остаётся в диалоге; можно оставить историю или повторить действие.
Снимок — 393 × 852 CSS px.

![Ошибка проверки перед очисткой истории](dialog-history-discard-error.png)

## Крупный текст: удаление проекта

Экран 360 × 480 CSS px, текст увеличен до 200%. Карточка прокручена к
действиям: длинное описание остаётся выше, обе кнопки доступны без
горизонтальной прокрутки. Высота каждой кнопки не меньше 44 CSS px.

![Удаление проекта с крупным текстом](dialog-project-delete-large-text.png)

## Крупный текст: очистка истории

Те же 360 × 480 CSS px и 200% текста. Пользователь может прочитать описание,
прокрутить к действиям и отменить очистку. Tab остаётся внутри диалога.

![Очистка истории с крупным текстом](dialog-history-large-text.png)
