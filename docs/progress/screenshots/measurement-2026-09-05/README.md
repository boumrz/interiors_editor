# Измерения · пользовательские сценарии · 5 сентября 2026

Четыре снимка работающего редактора. Проекты созданы через обычный интерфейс
в изолированных браузерных профилях. Каталог использует локальные ресурсы
репозитория через тестовый API. Это эмуляция телефона, не проверка на
физическом устройстве. Стены и 3D показаны на 393 × 852 CSS px,
выбор комнаты и изменённый план — на 360 × 740 CSS px.

## Расстояние между стенами

Обе стены подписаны; результат 3100 мм измеряется между их осями.
Кнопка позволяет выбрать другую цель с тем же началом.

![Расстояние между стенами](measurement-wall-distance.png)

## Измерение от предмета до комнаты

Источник остаётся виден над списком. Комнаты различаются по номеру;
подпись объясняет, что измерение выполняется до внутренней границы.

![Выбор комнаты для измерения](measurement-room-picker.png)

## Расстояние между предметами в 3D

Два одинаковых комода различаются по номеру. В 3D показано то же
кратчайшее расстояние между габаритами на плане; переключение вида
не создаёт новую ревизию проекта.

![Расстояние между предметами в 3D](measurement-items-3d.png)

## План изменился после измерения

После отмены изменения прежние подписи остаются для контекста,
а устаревшее число скрывается. «Выбрать заново» начинает с первой цели.

![Повторный выбор после изменения плана](measurement-stale.png)
