# Редизайн · пользовательские сценарии · 5 сентября 2026

14 скриншотов работающего приложения. Проекты и квартира созданы через обычный интерфейс; автоматизированные сценарии используют изолированные браузерные профили. Дополнительные снимки офлайна и недоступного каталога сделаны в отдельном проверочном проекте. Для каталога используется репозиторный API fake с локальными ресурсами. Это эмуляция телефона, не новая проверка физических устройств. Экран проектов — 360 × 740 CSS px; основные снимки редактора — 393 × 852 CSS px; восстановление 3D — 390 × 664 CSS px.
