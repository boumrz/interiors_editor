# Сохранение и восстановление · 5 сентября 2026

Шесть снимков работающего редактора из полного браузерного прогона.
Проекты созданы через обычный интерфейс в изолированных профилях;
отказы записи и повреждения локальных данных воспроизведены тестами.
Это эмуляция телефона, не проверка на физическом устройстве.

## План меблированной квартиры

Обычный рабочий сценарий для контекста: четыре комнаты, двери, окна и
размещённая мебель. Каталог использует локальные ресурсы репозитория через
тестовый API. План и 3D сняты на 393 × 852 CSS px.

стен помогает осмотреть комнаты и не меняет сам план.

![Повторно открытая квартира в 3D](reference-apartment-3d-reopened.png)

## Не хватает места для сохранения

Редактор показывает причину отказа и предлагает повторить запись или
скачать последнюю сохранённую версию. Подпись объясняет, что ожидающая
сохранения правка в файл не войдёт. Скачивание не теряет эту правку:
после освобождения места её можно сохранить повторной попыткой.
Снимок — 393 × 852 CSS px.

![Ошибка сохранения и доступные действия](safety-save-failure.png)

## Недоступны модели из истории

Текущая сохранённая версия здорова. Отдельная карточка позволяет проверить
историю снова или перейти к явному подтверждению её удаления.
Удаление истории не меняет текущую версию проекта.
Снимок — 390 × 664 CSS px.

![Восстановление ресурсов истории](safety-history-recovery.png)

## В проекте отсутствуют исходные модели

Экран объясняет остановку редактирования. Можно предоставить точные GLB
или перейти к подтверждённому удалению недоступных моделей одной операцией.
Во время проверки файлов связанные действия и возврат к проектам
временно недоступны. Снимок — 390 × 664 CSS px.

![Восстановление недоступных моделей проекта](safety-resource-recovery.png)

## Сохранённая версия не прошла проверку

Если нет подтверждённого контекста восстановления моделей, экран предлагает
повторную проверку и возврат к проектам. Он не показывает форму создания
нового проекта или загрузку GLB, которые не решают эту ошибку.
Локальные данные остаются на устройстве. Снимок — 360 × 640 CSS px.

![Проверка сохранённой версии проекта](safety-project-recovery.png)

Экспорт несохранённой правки как recovery data, восстановление из Portable
Backup и отдельный интерфейс загрузки файлов для ремонта истории остаются
дальнейшей функциональной работой.
