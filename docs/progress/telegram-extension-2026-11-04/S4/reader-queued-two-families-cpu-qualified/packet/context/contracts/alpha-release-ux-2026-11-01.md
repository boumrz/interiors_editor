## Проверка

Для изменений поведения: сначала воспроизводящий RED, затем GREEN. Геометрия/состояния проверяются Rstest; пользовательские сценарии — Playwright на мобильной эмуляции, включая реальные touch events. Отдельно проверяются ошибки, отмена, сохранение, reload, undo/redo, узкие экраны и PWA/offline. Изменённые критические ветки проходят mutation-проверку. В конце — полный web, production PWA и backend регресс; числа и ограничения сообщаются по фактическим результатам, без заявления о 100% покрытии без измерения.

## Решения по стенам и масштабу

[ГОСТ 21.201-2011](https://protect.gost.ru/gost/details/a7ca3664-3906-4158-9b28-0cb7acbe9be9) задаёт условные графические изображения, а [ГОСТ 21.501-2018](https://protect.gost.ru/gost/details/a241e289-aac3-4ee2-ad44-3259f9774799) — правила выполнения архитектурных чертежей. Эти документы не задают единую толщину всех стен квартиры. Поэтому 100 мм остаётся явно названным допущением Alpha для новой перегородки; несущая способность и материал из такого изображения не выводятся. Изменение толщины и автоматическое переписывание существующих проектов не входят в запрос.

На крупном плане проблема возникает из-за масштаба «весь план»: один и тот же шаг в миллиметрах занимает слишком мало пикселей. Увеличение ограничивается относительно физического шага, а не только относительно первоначального fit. Предельный масштаб позволяет представить 100 мм как 44 CSS px. Pinch удерживает мировую точку под серединой пальцев; кнопки +/− меняют масштаб вокруг центра холста. Размеры сохраняются в миллиметрах, а не пересчитываются из округлённого экрана. Второй палец отменяет незавершённое построение перед навигацией.

Для замыкания комнаты не требуется попасть пальцем точно в торец: нормализация жеста убирает покрытое начало и коллинеарное наложение. Если конечная точка привязана к существующему сегменту, намеренный путь через внутренние перегородки сохраняется. Иначе случайное продолжение обрезается на первом допустимом контакте. Пользователь видит результат до подтверждения. Точные числовые команды сохраняют строгую проверку; нецелочисленное пересечение не округляется ради принятия неверного графа.

Производный контур стены общий для 2D и обоих 3D-рендереров. Угол строится по пересечению боковых граней, ограничивает острый выступ и сохраняет материал в T/X-стыках. Проёмы вычитаются из того же контура, а свободный торец остаётся на исходном конце сегмента. Это изображение доменного графа, а не новая геометрическая модель проекта.
