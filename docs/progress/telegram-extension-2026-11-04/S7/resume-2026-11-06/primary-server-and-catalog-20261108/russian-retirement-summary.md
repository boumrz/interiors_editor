# Российский VPS: подготовка к удалению

Инвентаризация завершена, зашифрованная копия проверена полным чтением. Сам VPS **не удалён**. Его службы продолжают работать; DNS не менялся. Окончательное удаление и применение плана очистки DNS не входят в эту подготовку.

## Найденные приложения и данные

- Единственные рабочие Nginx virtual hosts — `domiknote.ru` и `www.domiknote.ru`, обслуживающие уже перенесённый InteriorsEditor. Единственный upstream — read-only каталог `127.0.0.1:4174`.
- Единственные прикладные container/volume — `interiors-editor-catalog-pg18`, порт `127.0.0.1:55432`. Базы: `interiors_catalog` около 77,9 МБ и `postgres` около 7,86 МБ. В default `postgres` нет пользовательских таблиц.
- Других приложений, сайтов или пользовательских БД не найдено. `/home`, `/srv`, `/var/www`, `/mnt`, `/media` пусты. Около 410 МиБ в `/root` занимает преимущественно установка `.nvm`/Node; инструменты сохранены в копии. В `/opt` находятся InteriorsEditor и пустые служебные папки containerd.
- Активных записей root crontab и root user services нет. Остальные работающие службы и timers относятся к ОС, мониторингу и уже учтённым Docker/Nginx/catalog.
- Корневое дерево и временные папки также проверены: дополнительных каталогов с проектами владельца не найдено.

В DNS ещё есть четыре A-ссылки на старый IP: `*.domiknote.ru`, `rgzheltov.domiknote.ru`, `*.rgzheltov.domiknote.ru`, `interview.domiknote.ru`. Эти записи сами по себе не доказывают наличие другого приложения на VPS: рабочие настройки и данные этого не подтверждают. Реальный InterHub находится на `interview.vtools.tech` → `37.18.73.150`. `dana.domiknote.ru` указывает на `192.168.1.122` и не связан с удаляемым IP. Для будущей уборки DNS подготовлен отдельный план; сейчас записи сохранены.
