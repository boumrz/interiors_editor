# Мобильная TMA — каталог, редактирование окна и поворот

24 ноября 2026 опубликована сборка `525a861df10cd4de`.
Предыдущая сборка `da2cc61c83e081ad` доступна для отката.

1. Каталог открывается выше. Строка категорий компактнее и сохраняет цели
   касания от 44 CSS px. Сетка прокручивается внутри шторки. Импорт
   собственного GLB находится во вкладке «Мои модели».
2. «Изменить окно» показывает ширину и высоту. Валидация и запись используют
   точные смещение и высоту подоконника из текущей ревизии. Перенос окна
   доступен непосредственно на плане.
3. Панель поворота на плане учитывает фактические границы карточки
   «Параметры» с первого выбора, при смене предмета и при изменении вьюпорта.
   Когда весь ряд помещается, доступны кнопки и точный ввод угла. В тесной
   области панель скрывается до восстановления свободного места.
   [Контракт TMA](../../_bmad-output/specs/spec-interiors-editor-alpha/telegram-mobile-editor-contract.md)

## Проверка

- В WKWebView iOS Simulator и Android System WebView в Android Emulator
  высота сетки каталога в проверенном портрете выросла с 219 до 440 CSS px.
  Полностью видны два ряда. Жест прокручивает карточки. Системная
  клавиатура сохраняет доступ к поиску. Вызов выбора GLB проверен из
  «Мои модели». В коротком Android сработал предел безопасной области,
  категория сохранила полный размер цели касания.
- В обоих нативных WebView окно сохранено с габаритами 1300 × 1100 мм.
  Свойства в IndexedDB подтвердили исходное смещение 1737 мм, высоту
  подоконника 837 мм и запись новых габаритов.
- Пройдены по шесть выделений с чередованием двух предметов, масштабирование
  и имитация короткой видимой области Telegram. В портрете 360 × 726 CSS px
  на Android и 440 × 860 CSS px на iOS рамки проверялись по кадрам. Наложений
  нет. На высоте 330 CSS px панель поворота скрылась и вернулась после
  восстановления видимой области.
- Прошли 3 745 модульных тестов, TypeScript, Biome и проверка границ
  архитектуры. Мутационная проверка размещения панели обнаружила 81 из
  84 мутаций. Для сохранения окна обнаружены две направленные мутации.
  Физические устройства с клиентом Telegram в этом прогоне недоступны.
