Версия `66b075ae9d045d69` доступна для отката.

- Пересечение напольных предметов блокирует постановку, копирование,
  перемещение, поворот и изменение размеров. Проверка общая для плана и 3D.
  При отказе сохранённая ревизия остаётся прежней. Касание краями допустимо,

  защиту черновика. [Контракт TMA](../../_bmad-output/specs/spec-interiors-editor-alpha/telegram-mobile-editor-contract.md)

## Проверка

- На предыдущей сборке Android WebView записал новый номер ревизии при
  переносе стула поверх второго. На новой сборке WKWebView и Android
  System WebView сохранили исходные координаты и номер ревизии. Подтверждение
  нового пересекающегося стула заблокировано. При числовом изменении
  ширины на 4200 мм показана причина рядом с полем. Ревизия снова осталась
  прежней.
- Android WebView повторно открыл синтетический проект с пересечением из
  предыдущей сборки, показал причину при выборе и сохранил раздвинутое
  положение. Открытие проекта сохранило исходную ревизию.
- В iOS Simulator и Android Emulator сверены нижняя привязка, слой,
  отсутствие ручки, положение трёх вкладок, внутренняя прокрутка каталога
  и системная клавиатура. Вход выполнен с синтетической подписанной сессией.
  Физическая приёмка по NFR-28 остаётся открытой.
- Прошли 3 736 модульных тестов, TypeScript, Biome и проверка границ
  архитектуры. Для проверки пересечений обнаружено 39 из 42 мутаций,
  оставшиеся три эквивалентны для доступного входа. Обнаружены три
  направленные мутации обработки пересечения в интерфейсе.
