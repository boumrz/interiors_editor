# Поддержка в Telegram

Служба читает личные сообщения @InteriorsEditorBot, доставляет обращения
в личку одного владельца и направляет его ответы автору. SQLite в
`/var/lib/interiors-telegram-support/support.sqlite3` хранит черновики,
очередь и привязки ответов. Фото передаются по идентификаторам Telegram.
Остановка службы сохраняет очередь и данные редактора.

## Подготовка и включение

1. Проверьте, что [правила поддержки](https://domiknote.ru/legal/2026-11-24.2/telegram-support-privacy.html)
   опубликованы, а BotFather сохраняет запуск редактора через меню.
2. Из каталога этого выпуска выполните `sudo sh install.sh`. Установщик
   создаёт служебного пользователя, устанавливает полный комплект и
   перечитывает systemd. Включение и перезапуск выполняются отдельно.
   `sh install.sh --stage EXISTING_DIRECTORY` проверяет раскладку локально.
3. Передайте действующий токен из защищённого хранилища в
   `/etc/interiors-editor/telegram-support/bot-token`. Файл принадлежит
   root и имеет режим `0600`. Передавайте содержимое из файла или по
   защищённому stdin. Токен не вводится в аргументах команд, чате или CI.
4. Выполните `sudo python3 -B /usr/local/lib/interiors-telegram-support/current/service.py check`.
   Команда подтверждает ID и имя бота и отсутствие webhook. Если webhook
   задан либо бот уже обслуживается другим процессом, согласуйте перенос
   с его оператором до включения новой службы.
5. Выполните `sudo python3 -B /usr/local/lib/interiors-telegram-support/current/service.py bind-owner`
   и отправьте выведенную одноразовую команду из своего аккаунта в личный
   чат @InteriorsEditorBot. Проверка пишет защищённые файлы `owner-chat-id`
   и `accept-from`, сохраняя входящие обновления Telegram для обработчика.
   При заполненной очереди Telegram без кода команда завершится с
   `owner-bind-backlog-full`. Повторите позже либо согласуйте обработку
   очереди с прежним оператором.
6. Выполните `sudo systemctl enable --now interiors-telegram-support.service`.
   Проверьте `systemctl is-active interiors-telegram-support.service`.
   Только после проверки из отдельного аккаунта добавьте `/support` в
   публичные команды. Оставьте основную кнопку входа в Mini App.

## Язык и персональный вход в Mini App

В личном чате `/language` сохраняет русский или английский язык. Бот
использует выбор для сообщений, новой кнопки в `/start` и меню этого чата.
Без явного выбора действует русский для русского языка Telegram и английский
для остальных языков. При недоступности ключа остаются работающий чат и
общая кнопка входа. После восстановления ключа повторный выбор обновит меню.

1. Подготовьте отдельный неизменяемый ключ Ed25519 в формате PKCS#8 PEM.
   Установите его с владельцем root и правами `0600` в
   `/etc/credstore/interiors-telegram-language-key`. Службе нужен OpenSSL 3.
   Редактору требуется только соответствующий публичный ключ. Сохраните
   резервную копию ключа отдельно от репозитория.
2. Выложите редактор, сверив его публичный ключ с ключом службы. Затем
   установите выпуск бота и перезапустите службу. Перед добавлением команды
   проверьте выбор языка и оба способа открытия из личного чата.
3. Зарегистрируйте описания команд для личных чатов через
   `sudo python3 -B /usr/local/lib/interiors-telegram-support/current/service.py publish-commands`.
   Английские описания используются по умолчанию. Для русского языка Telegram
   опубликован отдельный набор.

## Проверка и сбои

С отдельного аккаунта отправьте обычное сообщение и проверьте подсказку с
командами. Откройте `/support`, дождитесь инструкции и отправьте описание
обычной кнопкой Telegram. Сверьте номер у автора и владельца. В течение
15 минут добавьте фото к тому же обращению. Ответьте в личке на сообщение
бота с обращением или фото и подтвердите, что ответ получил автор.
Черновики из прежней версии сохраняют своё подтверждение кнопкой.
Вход в редактор проверяется отдельно в мобильном Telegram.

`sudo python3 -B /usr/local/lib/interiors-telegram-support/current/service.py status`
показывает безопасные статусы и номера заданий для оператора.
Если Telegram мог принять запрос до обрыва соединения, сначала проверьте
чат и номер обращения. Для подтверждённо недоставленного задания
выполните `sudo python3 -B /usr/local/lib/interiors-telegram-support/current/service.py retry-uncertain JOB`.
Команда ставит запись в очередь. Служба отправляет её отдельным шагом.

Для отключения выполните `sudo systemctl disable --now interiors-telegram-support.service`.
Данные, настройки и ранее установленный выпуск сохраняются. При замене
файлов установщиком перезапустите службу после проверки и сверки журнала
доставки. Ошибка `poll-conflict` означает, что Telegram обнаружил другого
потребителя. Устраните конфликт до перезапуска.

Из корня репозитория выполните
`python3 -B -m unittest scripts.telegram_support.test_service scripts.telegram_support.test_support`.
